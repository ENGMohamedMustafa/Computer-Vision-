# Traffic Light Color Detection App

A web application built with **Streamlit** and **YOLOv5** that detects traffic lights in images and classifies their color (Red, Yellow, Green) using color segmentation in the HSV color space.

---

## 🚦 Features

- Upload an image (`.jpg`, `.png`, `.jpeg`, `.webp`).
- Detect traffic lights using **YOLOv5s**.
- Classify the traffic light color (Red, Yellow, Green) based on pixel color in HSV space.
- Display bounding boxes and detected color for each traffic light.
