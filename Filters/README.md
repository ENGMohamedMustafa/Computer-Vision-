# Filters App 🎨

A lightweight and interactive web application built with **Streamlit** that allows users to apply a variety of filters to uploaded images in real time using **OpenCV**.

---

## 📸 Features

- Upload an image in `PNG`, `JPG`, `JPEG`, or `WEBP` format.
- Apply different filters:
  - **Black & White**
  - **Pencil Sketch**
  - **HDR (High Dynamic Range Enhancement)**
  - **Stylization**
  - **Brightness Adjustment**
- Real-time sliders to adjust filter parameters.

---

## 🔧 Filters Overview

| Filter        | Description                                                  |
|---------------|--------------------------------------------------------------|
| Black & White | Converts image to grayscale.                                |
| Pencil Sketch | Simulates a pencil-drawn version of the image.              |
| HDR           | Enhances image details and texture for dramatic effect.     |
| Stylization   | Converts image into a cartoonish artistic version.          |
| Brightness    | Adjust brightness levels from -50 to +50 using a slider.    |
