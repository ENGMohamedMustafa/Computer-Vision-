# Face Verification App

A web-based face verification tool built with **Streamlit** and powered by **DeepFace**. This app allows users to upload two face images and verify whether they belong to the same person using pre-trained deep learning models.

---

## 👨‍💻 Features

- Upload two face images.
- Uses DeepFace to compare the facial features.
- Returns a verification result indicating whether both images are of the same person.
- Displays both images side by side for comparison.
- Lightweight interface with instant results.
