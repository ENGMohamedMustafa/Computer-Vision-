# Human Emotion Recognition App

A simple, lightweight Streamlit web application that detects and classifies human emotions from uploaded images using DeepFace.

---

## 💡 Features

- Upload any image (JPG, PNG, JPEG, or WebP).
- Automatically detects human faces and classifies their emotions.
- Displays the original image and the detected dominant emotion.
- Uses DeepFace for high-quality emotion recognition.
