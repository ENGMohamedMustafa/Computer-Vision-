# Human Emotions Recognition Application

This is a Streamlit-based web application that detects and recognizes human emotions from images and videos using the DeepFace library. The app provides an intuitive interface for users to upload media files and receive real-time emotion analysis.

---

## Features

- Upload images or videos for emotion detection.
- Detect dominant emotions from human faces in images.
- Process videos by analyzing frames at set intervals and overlay detected emotions on the video.
- Handle cases where no faces are detected gracefully.
- Simple and responsive user interface for seamless interaction.

---

## Requirements

The application depends on the following Python packages:

- streamlit
- opencv-python
- numpy
- Pillow
- deepface
