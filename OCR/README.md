# Document Scanner Application

A lightweight and intuitive **Streamlit** web app for scanning and extracting text from images using **Tesseract OCR**.

---

## 📄 Features

- Upload images (`.jpg`, `.png`, `.jpeg`, `.webp`) containing printed or handwritten text.
- Automatically extracts text using **Tesseract OCR**.
- Displays the uploaded image and shows the extracted text line-by-line.
- Responsive user interface built with Streamlit.

---

## 🚀 Demo

### Upload an Image:
- A document, receipt, note, signboard, etc.

### App will:
- Show the uploaded image.
- Extract and display the text content using `pytesseract`.
